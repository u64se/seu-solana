# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| `0.1.x` | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, invariant violation, or runtime flaw in `u64se-seu-solana`:

1. **Do not disclose the issue publicly** via GitHub Issues or public discussions.
2. Please submit your findings privately via [GitHub Private Vulnerability Reporting](https://github.com/u64se/seu-solana/security/advisories/new).
3. Useful details to include:
   - Affected commit hash or release tag
   - Description of the invariant violation or exploit vector
   - Minimal reproduction case, test script, or Z3 counterexample (`.smt2`)

We appreciate responsible security research and will work to investigate and resolve confirmed findings.
